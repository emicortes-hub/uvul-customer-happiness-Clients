# UVUL Customer Happiness — demo

Prototipo estático listo para publicar en Netlify desde GitHub.

## Publicación

1. Sube el contenido de esta carpeta a la raíz de un repositorio de GitHub.
2. En Netlify, elige **Add new site → Import an existing project** y conecta ese repositorio.
3. Usa la rama principal del repositorio. No se necesita comando de build; el directorio de publicación es `.` (ya está definido en `netlify.toml`).
4. Deja activadas las publicaciones automáticas. Netlify publicará cada nuevo commit que subas a la rama conectada.

## Alcance de esta demo

El formulario, las respuestas y el seguimiento son simulados y funcionan solo en la página abierta. No guarda ni envía datos, no se conecta con correo, WhatsApp, sistemas de casos ni proveedores de IA. No ingreses datos reales o sensibles.

El catálogo incluido es ilustrativo y editable en `index.html`; los nombres oficiales de programas están pendientes de confirmación.
